# dls-computer
Save files for my 4-bit computer in [Digital Logic Sim](https://github.com/SebLague/Digital-Logic-Sim)!

# Instruction set
- instruction: code > in0, in1, in2, in3
- data set: 00 > bit0, bit1, bit2, bit3
- mux select: 01 > sel a, sel b
- reg store: 10 > reg a, reg b
- alu mode: 11 > add, sub, diff
