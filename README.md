# dls-computer
Save files for my 4-bit computer in [Digital Logic Sim](https://github.com/SebLague/Digital-Logic-Sim)!

# Instruction set
- instruction: opcode > in 3, in 2, in 1, in 0
---
- data set: 00 > bit 3, bit 2, bit 1, bit 0
- mux and reg: 01 > sel a, sel b, reg a, reg b
- alu operation: 10 > add, sub, diff, inc
- clock mode: 11 > manual, 1hz, halt
