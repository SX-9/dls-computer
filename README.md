# dls-computer
Save files for my 4-bit computer in [Digital Logic Sim](https://github.com/SebLague/Digital-Logic-Sim)!

# Instruction set
instruction: code > arg1, args...
data set: 000 > bit0, bit1, bit2, bit3
mux select: 001 > sel a, sel b
reg store: 010 > reg a, reg b
alu mode: 011 > diff, sub, add,
